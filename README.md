# RP Memory Public Test

A harmless test repository for verifying ChatGPT GitHub connector access and archive-maintenance workflows.

> **Public repository warning:** This repository contains generic templates only. Never store real roleplay archives, personal information, private messages, credentials, API keys, or production data here.

## Test documents

- [Project archive template](docs/PROJECT_TEMPLATE.md)
- [Event record template](docs/EVENT_TEMPLATE.md)

## What this test covers

1. Read repository metadata and files.
2. Create and update files through the authorized GitHub connector.
3. Read committed files back to verify the saved content.
4. Validate project separation, event history, knowledge boundaries, corrections, and rollback practices.

## Important boundary

This is a public smoke-test repository, not a destination for real project data. Any future real archive must use a separately verified private repository with a narrowly scoped installation.
